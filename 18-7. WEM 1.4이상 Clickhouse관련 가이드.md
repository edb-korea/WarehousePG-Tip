# ClickHouse 가이드 for WEM v1.4 이상.

## 1. vm.max_map_count 확인 및 변경

### 현재 설정값과 사용값 확인

```bash
sudo cat /proc/sys/vm/max_map_count
sudo cat /proc/$(pidof clickhouse-server)/maps | wc -l
```

### vm.max_map_count 변경

```bash
sudo sysctl -w vm.max_map_count=262144
echo "vm.max_map_count=262144" | sudo tee /etc/sysctl.d/99-clickhouse.conf
sudo sysctl --system
```

### 테이블별 파트 수 확인

```sql
SELECT table, count() AS parts
FROM system.parts
WHERE active AND database = 'acp_observability'

ORDER BY parts DESC;
```

## 3. 테이블 보관 주기(TTL)

### TTL 확인

```sql
SELECT name, engine_full
FROM system.tables
WHERE database = 'acp_observability' AND engine_full LIKE '%TTL%';
```

### TTL 변경

```sql
ALTER TABLE acp_observability.otel_logs MODIFY TTL Timestamp + INTERVAL 14 DAY;
ALTER TABLE acp_observability.otel_metrics_gauge MODIFY TTL TimeUnix + INTERVAL 30 DAY;
```

## 4. 용량 확인

### 테이블별 용량과 가장 오래된 데이터 시점

```sql
SELECT
    table,
    sum(rows) AS rows,
    formatReadableSize(sum(bytes_on_disk)) AS size,
    min(min_time) AS oldest,
    count() AS parts
FROM system.parts
WHERE active AND database = 'acp_observability'
GROUP BY table
ORDER BY sum(bytes_on_disk) DESC;
```

### 디스크 여유 공간 확인

```sql
SELECT name, formatReadableSize(free_space) AS free, formatReadableSize(total_space) AS total
FROM system.disks;
```

### 전체 DB 크기 비교

```sql
SELECT database, formatReadableSize(sum(bytes_on_disk)) AS size
FROM system.parts
WHERE active
GROUP BY database
ORDER BY sum(bytes_on_disk) DESC;
```

### DB 내 테이블별 사용량 (디스크 압축 기준)

```sql
SELECT
    database,
    table,
    formatReadableSize(sum(bytes_on_disk)) AS disk_size,
    formatReadableSize(sum(data_uncompressed_bytes)) AS uncompressed,
    round(sum(data_uncompressed_bytes) / sum(data_compressed_bytes), 2) AS ratio,
    sum(rows) AS rows,
    count() AS parts,
    min(min_time) AS oldest,
    max(max_time) AS newest
FROM system.parts
WHERE active AND database = 'acp_observability'
GROUP BY database, table
ORDER BY sum(bytes_on_disk) DESC;
```
