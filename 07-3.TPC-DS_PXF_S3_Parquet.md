#### TPC-DS 데이터를 PXF를 통해서 Object Storage(S3/Minio) 에 이동 시킨 후, TPC-DS 수행 하는 방법

# 1. 전체 데이터를 PXF 를 통해서 S3(Minio)에 이동 (TPC-DS, Parquet)
> 기준:
> - WHPG version: 7
> - 원본 데이터: `gpadmin` database의 `tpcds` schema 전체 데이터
> - 대상 저장소: MinIO S3-compatible object storage
> - 저장 포맷: Parquet
> - bucket: `tpcds-pxf-parquet`
> - PXF server name: `minio_tpcds`

## 1. 구성 목적

WHPG 내부 `tpcds` schema의 전체 TPC-DS 데이터를 PXF writable external table을 통해 MinIO에 Parquet 형식으로 이동하고, 다시 WHPG에서 조회 가능한 구조로 구성한다.

전체 데이터는 TPC-DS 논리 테이블 24개를 의미한다. 원본이 파티션 테이블인 경우 최종 조회 테이블도 WHPG parent partition table로 만들고, 각 partition은 PXF readable external table을 `ATTACH PARTITION`으로 연결한다.

```text
WHPG tpcds partition parent
  -> source child partition별 PXF writable external table
  -> MinIO bucket, partition별 Parquet path
  -> partition별 PXF readable external table
  -> WHPG parent partition table에 ATTACH PARTITION
  -> 최종 사용자는 parent partition table 조회
```

## 3. TPC-DS 원본 구조 확인

논리 테이블 수 확인:

```sql
SELECT count(*)
FROM pg_class c
JOIN pg_namespace n ON n.oid = c.relnamespace
WHERE n.nspname = 'tpcds'
  AND c.relkind IN ('r', 'p')
  AND NOT EXISTS (
      SELECT 1
      FROM pg_inherits i
      WHERE i.inhrelid = c.oid
  );
```

예상 결과:

```text
24
```

파티션 테이블 확인:

```sql
SELECT
    parent_ns.nspname AS parent_schema,
    parent.relname AS parent_table,
    child.relname AS child_table,
    pg_get_expr(child.relpartbound, child.oid) AS partition_bound
FROM pg_inherits i
JOIN pg_class parent ON parent.oid = i.inhparent
JOIN pg_namespace parent_ns ON parent_ns.oid = parent.relnamespace
JOIN pg_class child ON child.oid = i.inhrelid
WHERE parent_ns.nspname = 'tpcds'
ORDER BY parent.relname, child.relname;
```

## 6. Schema 생성

`gpadmin` database에서 수행한다.

```sql
CREATE EXTENSION IF NOT EXISTS pxf;

CREATE SCHEMA IF NOT EXISTS tpcds_pxf_s3;
```

schema 용도:

| schema | 용도 |
| --- | --- |
| `tpcds_pxf_s3` | PXF -> S3 케이스 전체 schema. 최종 조회 테이블, partition별 readable external table, export용 writable external table을 모두 보관 |

같은 schema 안에서는 object name prefix로 용도를 구분한다.

| 이름 규칙 | 용도 |
| --- | --- |
| `<table_name>` | 최종 조회 대상. 비파티션은 PXF readable external table, 파티션은 WHPG parent partition table |
| `ext_<child_partition_table>` | parent partition table에 attach할 partition별 readable PXF external table |
| `w_<table_or_child_partition_table>` | MinIO로 export하기 위한 writable PXF external table |

## 7. 전체 데이터 Export 규칙

PXF Parquet writable external table 기본 형식:

```sql
CREATE WRITABLE EXTERNAL TABLE tpcds_pxf_s3.w_<table_or_partition_name>
(<column_name> <data_type>, ...)
LOCATION ('pxf://tpcds-pxf-parquet/tpcds/<path>?PROFILE=s3:parquet&SERVER=minio_tpcds')
FORMAT 'CUSTOM' (FORMATTER='pxfwritable_export')
DISTRIBUTED BY (<source_distribution_key>);
```

파티션별 PXF Parquet readable external table 기본 형식:

```sql
CREATE EXTERNAL TABLE tpcds_pxf_s3.ext_<child_partition_table>
(<column_name> <data_type>, ...)
LOCATION ('pxf://tpcds-pxf-parquet/tpcds/<table_name>/<child_partition_table>?PROFILE=s3:parquet&SERVER=minio_tpcds')
FORMAT 'CUSTOM' (FORMATTER='pxfwritable_import');
```

파티션 parent table 기본 형식:

```sql
CREATE TABLE tpcds_pxf_s3.<table_name>
(<column_name> <data_type>, ...)
DISTRIBUTED BY (<source_distribution_key>)
PARTITION BY RANGE (<partition_key>);

ALTER TABLE tpcds_pxf_s3.<table_name>
ATTACH PARTITION tpcds_pxf_s3.ext_<child_partition_table>
FOR VALUES FROM (<start_value>) TO (<end_value>);
```

경로 규칙:

| 원본 유형 | S3 경로 |
| --- | --- |
| 비파티션 테이블 | `tpcds/<table_name>` |
| 파티션 테이블 | `tpcds/<table_name>/<child_partition_table>` |

### 8.3 전체 TPC-DS DDL 자동 생성

고객 환경에서는 TPC-DS 전체 24개 논리 테이블을 대상으로 해야 하므로 수동 작성 대신 자동 생성 스크립트를 사용한다.

`generate_pxf_s3_parquet_ddl.sh` 스크립트를 WHPG coordinator에 복사한 뒤 `gpadmin` 사용자로 실행한다.

> WHPG/PXF external table 생성 구문에서는 컬럼 정의에 `NOT NULL` 같은 제약조건을 넣지 않는다. 자동 생성 스크립트는 DB catalog에서 컬럼명과 데이터 타입을 조회해 `col type` 형태로 명시적으로 생성한다. 파티션 parent table도 같은 컬럼 정의를 사용해 partition별 readable external table을 attach할 때 `NOT NULL` 조건 불일치를 피한다.

> 재실행 시 같은 이름이 external table로 남아 있을 수도 있고, parent partition table로 남아 있을 수도 있다. 자동 생성 스크립트는 DB catalog의 `relkind`를 확인한 뒤 object 종류에 맞게 `DROP EXTERNAL TABLE` 또는 `DROP TABLE ... CASCADE`를 수행한다.

> source child partition 통계의 row estimate가 `0`인 경우에는 해당 partition의 writable external table, readable external table, `ATTACH PARTITION` 구문을 생성하지 않는다. PXF Parquet export는 빈 partition에 대해 읽을 수 있는 Parquet path를 만들지 않을 수 있으므로, 빈 path를 attach하면 이후 parent table 조회 또는 count 검증에서 `Input path does not exist` 오류가 발생할 수 있다. 이 판단은 `pg_class.reltuples` 값을 사용하므로 TPC-DS 적재 후 `analyze`가 수행된 상태를 기준으로 한다.

```bash
cd <WORK_DIR>

SOURCE_SCHEMA=tpcds \
TARGET_SCHEMA=tpcds_pxf_s3 \
BUCKET=tpcds-pxf-parquet \
PXF_SERVER=minio_tpcds \
OUT_FILE=pxf_s3_parquet_tpcds_all.sql \
bash generate_pxf_s3_parquet_ddl.sh
```

현재 테스트 기준 예시:

생성된 SQL은 다음 내용을 포함한다.

```text
1. PXF extension/schema 생성
2. 비파티션 테이블 writable external table 생성
3. 비파티션 테이블 INSERT export
4. 비파티션 테이블 readable external table 생성
5. 파티션 테이블 child partition별 writable external table 생성
6. 파티션 child별 INSERT export
7. 파티션 child별 readable external table 생성
8. 최종 조회용 parent partition table 생성
9. partition별 external table ATTACH PARTITION
10. 모든 테이블 구성 후 마지막에 테이블별 row count 확인 SQL
```

## 첨부. generate_pxf_s3_parquet_ddl.sh

```bash
#!/usr/bin/env bash
set -euo pipefail

OUT_FILE="${OUT_FILE:-pxf_s3_parquet_tpcds_all.sql}"
COUNT_FILE="$(mktemp)"
trap 'rm -f "${COUNT_FILE}"' EXIT

: "${DBNAME:?Set DBNAME to the target database name.}"
: "${SOURCE_SCHEMA:?Set SOURCE_SCHEMA to the source TPC-DS schema name.}"
: "${TARGET_SCHEMA:?Set TARGET_SCHEMA to the target schema name.}"
: "${BUCKET:?Set BUCKET to the target S3 bucket name.}"
: "${PXF_SERVER:?Set PXF_SERVER to the PXF server name.}"

psql -d "${DBNAME}" -v ON_ERROR_STOP=1 -Atc "select 1" >/dev/null

cat > "${OUT_FILE}" <<SQL
\\set ON_ERROR_STOP on

CREATE EXTENSION IF NOT EXISTS pxf;
CREATE SCHEMA IF NOT EXISTS ${TARGET_SCHEMA};

SQL

cat > "${COUNT_FILE}" <<SQL

--
-- Row count validation
--
SQL

emit_drop_table_or_external() {
  local object_name="$1"

  cat >> "${OUT_FILE}" <<SQL
DO \$\$
DECLARE
    v_relkind "char";
BEGIN
    SELECT c.relkind
      INTO v_relkind
      FROM pg_class c
      JOIN pg_namespace n ON n.oid = c.relnamespace
     WHERE n.nspname = '${TARGET_SCHEMA}'
       AND c.relname = '${object_name}';

    IF v_relkind IS NULL THEN
        NULL;
    ELSIF v_relkind = 'f' THEN
        EXECUTE format('DROP EXTERNAL TABLE %I.%I', '${TARGET_SCHEMA}', '${object_name}');
    ELSE
        EXECUTE format('DROP TABLE %I.%I CASCADE', '${TARGET_SCHEMA}', '${object_name}');
    END IF;
END
\$\$;
SQL
}

psql -d "${DBNAME}" -v ON_ERROR_STOP=1 -At -F '|' <<SQL | while IFS='|' read -r table_name relkind dist_clause part_key column_defs
SELECT
    c.relname AS table_name,
    c.relkind,
    COALESCE(pg_get_table_distributedby(c.oid), 'DISTRIBUTED RANDOMLY') AS dist_clause,
    COALESCE(pg_get_partkeydef(c.oid), '') AS part_key,
    (
        SELECT string_agg(
            format(
                '%I %s',
                a.attname,
                pg_catalog.format_type(a.atttypid, a.atttypmod)
            ),
            ', '
            ORDER BY a.attnum
        )
        FROM pg_attribute a
        WHERE a.attrelid = c.oid
          AND a.attnum > 0
          AND NOT a.attisdropped
    ) AS column_defs
FROM pg_class c
JOIN pg_namespace n ON n.oid = c.relnamespace
WHERE n.nspname = '${SOURCE_SCHEMA}'
  AND c.relkind IN ('r', 'p')
  AND NOT EXISTS (
      SELECT 1
      FROM pg_inherits i
      WHERE i.inhrelid = c.oid
  )
ORDER BY c.relname;
SQL
do
  if [[ -z "${column_defs}" ]]; then
    echo "ERROR: column definitions were not found for ${SOURCE_SCHEMA}.${table_name}" >&2
    exit 1
  fi

  cat >> "${COUNT_FILE}" <<SQL

SELECT '${table_name}' AS table_name,
       (SELECT count(*) FROM ${SOURCE_SCHEMA}.${table_name}) AS source_count,
       (SELECT count(*) FROM ${TARGET_SCHEMA}.${table_name}) AS pxf_count;
SQL

  if [[ "${relkind}" == "p" ]]; then
    if [[ -z "${part_key}" ]]; then
      echo "ERROR: partition key was not found for ${SOURCE_SCHEMA}.${table_name}" >&2
      exit 1
    fi

    cat >> "${OUT_FILE}" <<SQL

--
-- Partitioned table: ${SOURCE_SCHEMA}.${table_name}
-- Final query table: ${TARGET_SCHEMA}.${table_name}
--
SQL
    emit_drop_table_or_external "${table_name}"

    cat >> "${OUT_FILE}" <<SQL

CREATE TABLE ${TARGET_SCHEMA}.${table_name}
(${column_defs})
${dist_clause}
PARTITION BY ${part_key};
SQL

    psql -d "${DBNAME}" -v ON_ERROR_STOP=1 -At -F '|' <<SQL | while IFS='|' read -r child_name part_bound estimated_rows
SELECT
    child.relname AS child_name,
    pg_get_expr(child.relpartbound, child.oid) AS part_bound,
    CASE
        WHEN child.reltuples < 0 THEN -1
        ELSE child.reltuples::bigint
    END AS estimated_rows
FROM pg_inherits i
JOIN pg_class parent ON parent.oid = i.inhparent
JOIN pg_namespace parent_ns ON parent_ns.oid = parent.relnamespace
JOIN pg_class child ON child.oid = i.inhrelid
JOIN pg_namespace child_ns ON child_ns.oid = child.relnamespace
WHERE parent_ns.nspname = '${SOURCE_SCHEMA}'
  AND parent.relname = '${table_name}'
  AND child_ns.nspname = '${SOURCE_SCHEMA}'
ORDER BY child.relname;
SQL
    do
      s3_path="tpcds/${table_name}/${child_name}"

      if [[ "${estimated_rows}" == "0" ]]; then
        cat >> "${OUT_FILE}" <<SQL

-- Source partition: ${SOURCE_SCHEMA}.${child_name}
-- ${part_bound}
-- Skipped because source partition statistics show 0 rows. PXF Parquet export does not create a readable path for an empty partition.
SQL
        continue
      fi

      cat >> "${OUT_FILE}" <<SQL

-- Source partition: ${SOURCE_SCHEMA}.${child_name}
-- ${part_bound}
```
