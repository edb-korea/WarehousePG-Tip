## Drop-in 설정 파일 생성
### 수신할 네트워크 인터페이스 설정 (모든 IPv4 인터페이스 수힌 허용) (root)
```
sudo mkdir -p /etc/clickhouse-server/config.d /etc/clickhouse-server/users.d

sudo tee /etc/clickhouse-server/config.d/observability.xml >/dev/null <<'EOF'
<clickhouse>
    <listen_host>0.0.0.0</listen_host>
</clickhouse>
EOF

sudo chown root:clickhouse /etc/clickhouse-server/config.d/observability.xml
sudo \chmod 640 /etc/clickhouse-server/config.d/observability.xml
```

### 데이터 경로 설정
```
sudo tee /etc/clickhouse-server/config.d/data-path.xml >/dev/null <<'EOF'
<clickhouse>
    <path>/data1/clickhouse/</path>                              <!-- 데이터 루트, 끝의 / 필수 -->
    <tmp_path>/data1/clickhouse/tmp/</tmp_path>                  <!-- 대형 쿼리 임시 데이터 -->
    <user_files_path>/data1/clickhouse/user_files/</user_files_path>
    <format_schema_path>/data1/clickhouse/format_schemas/</format_schema_path>
    <custom_cached_disks_base_directory>/data1/clickhouse/caches/</custom_cached_disks_base_directory>
    <user_directories>
        <local_directory>
            <path>/data1/clickhouse/access/</path>               <!-- SQL로 만든 사용자/권한 저장소 -->
        </local_directory>
    </user_directories>
</clickhouse>
EOF

sudo chown root:clickhouse /etc/clickhouse-server/config.d/data-path.xml
sudo \chmod 640 /etc/clickhouse-server/config.d/data-path.xml
```

### 로그 경로 설정
```
sudo tee /etc/clickhouse-server/config.d/log-path.xml >/dev/null <<'EOF'
<clickhouse>
    <logger>
        <log>/data1/log_clickhouse/clickhouse-server.log</log>
        <errorlog>/data1/log_clickhouse/clickhouse-server.err.log</errorlog>
    </logger>
</clickhouse>
EOF

sudo chown root:clickhouse /etc/clickhouse-server/config.d/log-path.xml
sudo \chmod 640 /etc/clickhouse-server/config.d/log-path.xml
```

#### 경로 확인
```
sudo for k in path logger.log logger.errorlog logger.size logger.count logger.level; do
  echo -n "$k = "; clickhouse-extract-from-config --config-file /etc/clickhouse-server/config.xml --key $k
done
```
